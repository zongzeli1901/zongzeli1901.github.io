Neural Radiance Fields
from Scratch

Implementing the core NeRF pipeline in PyTorch to understand how continuous neural scene representations reconstruct 3D appearance from a sparse collection of 2D views.
PyTorch Neural Rendering Novel View Synthesis Positional Encoding Volume Rendering

Project Overview

The goal of this project was to understand NeRF at the implementation level rather than treat it as a black box. We built the core pipeline from scratch in PyTorch and trained it on the synthetic Lego scene, following the formulation introduced by Mildenhall et al.

What I Built

An end-to-end neural rendering pipeline that converts camera images and poses into rays, samples 3D locations along those rays, encodes continuous coordinates with sinusoidal features, predicts color and density using an MLP, and reconstructs pixel colors through differentiable volume rendering.

Implementation Details

Data Pipeline

Camera-Aware Dataset Loading

Built a custom PyTorch Dataset pipeline to load RGB frames, normalize image values, parse camera-to-world matrices, and preserve camera field-of-view information required for geometric ray construction.

Geometry

World-Space Ray Generation

Converted pixel coordinates into camera-space directions and transformed them into normalized world-space rays using camera extrinsics. Vectorized the operation for full image grids.

Representation

Multi-Frequency Positional Encoding

Encoded continuous spatial coordinates and viewing directions using sinusoidal frequency bands so the MLP could represent higher-frequency scene geometry and appearance.

Neural Network

NeRF MLP Architecture

Implemented an 8-layer MLP with width 256 and a skip connection. Position features predict density and latent features, while view-direction features produce view-dependent RGB color.

Sampling

Stratified Ray Sampling

Sampled 64 locations along each camera ray using randomized stratified sampling, allowing the neural field to be evaluated at continuous spatial positions during optimization.

Rendering

Differentiable Volume Rendering

Converted per-sample colors and densities into rendered pixel values using accumulated transmittance and alpha compositing, allowing gradients to propagate through the entire rendering pipeline.

Training Setup

Training was designed around randomly sampled rays rather than rendering full-resolution views at every iteration, reducing compute requirements during experimentation.

What Made It Difficult?

Camera Geometry
Small mistakes in coordinate conventions, transform orientation, or ray direction could produce completely black or distorted renders. Debugging required inspecting simple rays and validating camera geometry before blaming the network.
High-Frequency Detail
Direct coordinate inputs produced overly smooth reconstructions. Multi-frequency positional encoding was important for representing sharper geometry and appearance.
Compute Cost
Rendering full-resolution validation views repeatedly was too expensive during training. Low-resolution previews and randomly sampled rays made debugging and iteration much faster.
Sampling Efficiency
This implementation focused on the coarse stratified-sampling stage. Hierarchical importance sampling from the original NeRF formulation remains a natural extension for allocating more samples near visible content.

Connection to the Original NeRF Paper

NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis

This project was based on the core formulation introduced by Mildenhall et al. (2020): a continuous 5D neural scene representation queried along camera rays and rendered using differentiable volume rendering. Our implementation focused on reproducing and understanding the core coarse-stage pipeline in PyTorch, while hierarchical sampling was left as future work.

What I Took Away

The most valuable part of this project was learning how tightly geometry, representation, optimization, and rendering interact. A NeRF is not just an MLP: correct camera rays, sampling, coordinate encoding, transmittance, and optimization all have to work together before a meaningful scene appears.
